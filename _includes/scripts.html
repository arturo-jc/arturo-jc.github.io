{%- comment -%} The scripts, in every page's head. Include with fades=true on the home page, where the type fades in. The inline script runs before the first paint. Its class `js` hides each board's type until the board is drawn (styles.css), because until then the type sits in the plain column a page without the scripts shows, and would flash there before jumping to its seat. `fades` hides what fades in (js/fades.js). If the modules never run, both classes go after three seconds and the page shows its type in that column; main.js cancels this. Every module the page runs is preloaded, so that the browser fetches them all at once instead of finding each through the one that imports it: the shared ones in js/, which Jekyll lists, so a new one is preloaded without being added here, and the sections the page has boards for. Include with boards= the ids of those boards, which are also the sections' file names; each page sets them as `boards` in its front matter, a post in its layout's. main.js imports only the sections whose boards are on the page. {%- endcomment -%} {%- assign boards = include.boards | split: ' ' %} {%- for file in site.static_files %}{% if file.extname == '.js' and file.path contains '/js/' %} {%- if file.path contains '/js/sections/' %}{% unless boards contains file.basename %}{% continue %}{% endunless %}{% endif %} {%- endif %}{% endfor %}
